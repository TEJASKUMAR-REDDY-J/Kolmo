# Sample photos

`car.jpg`, `mug.jpg`, `wing.jpg` were drawn procedurally with OpenCV for Kolmo (simple shapes on noisy gradient
backgrounds; the wing is a NACA 0012 section at 8 deg). No third-party content; released with the repository (CC0).
Try: `python -m kolmo.geometry docs/samples/car.jpg --prompt car --out runs/geometry/car`.
